# Site vitrine — Thomas, graphiste freelance

Intégration HTML/CSS responsive d'une maquette Figma, réalisée dans le cadre du titre professionnel Développeur Web et Web Mobile.

## Site en ligne

https://souhill31.github.io/site-thomas/

## Technologies

- HTML5
- CSS3 (Flexbox, media queries)
- Police : Heebo, chargée via Google Fonts

## Installation

1. Cloner le dépôt : `git clone https://github.com/souhill31/site-thomas.git`
2. Ouvrir le dossier dans un éditeur de code
3. Ouvrir `index.html` dans un navigateur, ou utiliser l'extension Live Server de VS Code

## Structure du projet
site-thomas/
├── index.html
├── style.css
├── favicon.ico
└── images/

## Points de rupture responsive

- Ordinateur : au-delà de 1024 px
- Tablette : jusqu'à 1024 px
- Mobile : jusqu'à 768 px

## Accessibilité et validation

- Attribut `lang="fr"`, attributs `alt` descriptifs, labels de formulaire liés aux champs
- Hiérarchie de titres respectée (un seul `h1`)
- Navigation au clavier testée
- Code validé sans erreur par les validateurs HTML et CSS du W3C
